# MIxS Repository Documentation
This folder contains static documents that describe this repository, its editing policies, and workflows and guidance for editing.

For information on GSC see [The GSC website](https://www.gensc.org/)

For information on MIxS and its use, see [its autogenerated documentation](https://w3id.org/mixs).

The GSC uses LinkML tooling to maintain the MIxS schema. For guidance on how to use LinkML or contribute to the core LinkML code, please see [the LinkML documentation](https://linkml.io/linkml/).

## Code of Conduct

The MIxS team strives to create a welcoming environment for editors, users and other contributors.
Please carefully read our [Code of Conduct](https://github.com/GenomicsStandardsConsortium/mixs/blob/main/CODE_OF_CONDUCT.md) before making a contribution.

## Folder contents

* README.md: This file
* [about.md](about.md): A description of MIxS. This file is auto-generated by LinkML. For more information on MIxS, see [its autogenerated documentation](https://w3id.org/mixs).
* [edit_workflow.md](edit_workflow.md): Guidance for members of the GSC Technical Working Group on how to request and create a new checklist or package, request and create a new term, update an existing term, or report an issue with the MIxS code
* [releasing.md](releasing.md): How to cut a MIxS release: version numbers, the release action, the schema comparisons, and publishing
* [policy.md](policy.md): Policies for editing, versioning, and communication about MIxS releases
* [schema_element_deprecation_guide.md](schema_element_deprecation_guide.md): How a schema element is deprecated across two release cycles
* [SCHEMA_DIFFING.md](SCHEMA_DIFFING.md): How to compare two versions of the schema, and how release diff summaries are produced

Developer notes that are not published to the documentation site live in
[`contrib/docs/`](https://github.com/GenomicsStandardsConsortium/mixs/tree/main/contrib/docs).

## Contributing

How to write an issue, name a branch, open a pull request, and what the checks
will ask of you are all in
[CONTRIBUTING.md](https://github.com/GenomicsStandardsConsortium/mixs/blob/main/CONTRIBUTING.md).
That is the single entry point; this page previously repeated part of it.

**Labeling issues:** labels were last reviewed 2023/12. Please do not create new
labels on your own. Open an issue requesting one, for review by the TWG or CIG.
See the [labels page](https://github.com/GenomicsStandardsConsortium/mixs/labels)
for descriptions of existing labels.
